# Midnight Protocol — Dərin araşdırma

## Yekun xülasə

Midnight Protocol terminal və hakerlik janrında Hacknet-dən fərqli bir problem həll etməyə çalışır: hakerliyi sürətli əmrlərin icrası kimi yox, **növbə əsaslı taktiki qərar sistemi** kimi təqdim edir.

Oyun bunu üç əsas qatı birləşdirərək edir:

```text
özünü haker kimi hiss etmə
+
növbə əsaslı taktiki şəbəkə oyun gedişi
+
hekayə / etik seçim / nüfuz
```

Yoxlanmış Steam məlumat toplusu:

- 301 ingilisdilli rəy
- 253 müsbət
- 48 mənfi
- 84.05% müsbət rəy nisbəti

Əsas nəticə:

> **Midnight Protocol Hacknet-in dayaz “alət = açar” probleminə real mexaniki dərinlik əlavə edir, amma bunun əvəzində RNG (təsadüfi nəticə mexanizmi) və ədalətlilik, yenidən cəhd/bərpa, alət dəstinin qeyri-müəyyənliyi, yalnız klaviatura ilə idarəetmənin yaratdığı çətinlik və təlim hissəsindən sonrakı mürəkkəblik problemləri yaradır.**

Oyunun ən güclü tərəfləri:

- özünü haker kimi hiss etmə;
- oyuna dalma hissi;
- hekayə;
- növbə əsaslı planlama;
- alət dəsti/quruluş seçimi;
- etik seçim və nüfuz;
- üslublu UI və səs;
- seçilmiş həqiqilik hissi.

Ən ciddi problemlər:

- RNG səbəbilə uğursuzluğun oyunçu bacarığından ayrılması;
- geri qaytarma/yenidən cəhd modelinin bunu daha ağrılı etməsi;
- izlənmə sayğacı və gediş limitlərinin sınaq aparma ilə toqquşması;
- yalnız klaviatura ilə idarəetmənin bəzi hərəkətləri süni şəkildə yavaşlatması;
- təlim hissəsindən sonra 1–3 saatlıq mərhələdə yüksək çətinlik;
- daha çox sistem olmasına baxmayaraq müəyyən mərhələdə təkrarçılıq;
- bəzi qərar/nəticələrin həddindən artıq sərt və geri dönməz hiss olunması.

Ən vacib məhsul üzrə əsas dərs:

> **dərinlik təkrarçılıq problemini azalda bilər, amma dərinlik özü yaxşı dizayn demək deyil. Oyunçunun hər qərarı başa düşülən, planlana bilən və uğursuzluq zamanı izah edilə bilən olmalıdır.**

Hacknet ilə birlikdə baxanda artıq iki oyunlararası prinsip güclənir:

1. **tam realizm lazım deyil; seçilmiş həqiqilik hissi + ardıcıl rol hissi işləyir;**
2. **terminal/klaviatura ilə giriş rol hissini gücləndirir, amma qarşılıqlı əlaqənin səmərəliliyi pozulanda yenilik effekti çətinliyə çevrilir.**

Ətraflı rəy məlumatları:

`analysis/midnight-protocol/3. theme-analysis.md`

# 3. Midnight Protocol əslində necə oyundur?

Ən düzgün qısa təsvir:

> **yalnız klaviatura ilə interfeys daxilində oynanan növbə əsaslı taktiki şəbəkə üzərində rol oyunu və hekayə yönümlü tapmaca oyunu.**

Oyun real hakerlik simulator deyil.

Əsas tapşırıq dövrü:

```text
tapşırıq seç
→ mövcud məlumat oxu
→ proqramlar/avadanlıq loadout qur
→ network-ə daxil ol
→ qovşaq-lar arasında hərəkət et
→ ICE / SysOp / izlənmə idarə et
→ məqsəd və optional data tap
→ qərar ver
→ network-dən çıx
→ nüfuz/hekayə nəticəsi al
→ yeni tool / tapşırıq / branch aç
```

Hər turn-də əsas grammar sadədir:

- move;
- interact;
- ability/program;
- end turn.

Dərinlik həmin sadə grammar ətrafında qurulur.

# 8. əsas oyun dövrü və sistem dərinliyi

Midnight Protocol Hacknet-dən daha dərin əsas oyun dövrü qurur.

Əlavə qərar qatlari:

- SysOp;
- route;

Bu real improvement-dir.

Amma iki problem qalır.

## 8.1. Mandatory alətlər real seçim-ni azalda bilər

Bir rəydə oyunçu 5 slot-dan:

- cloak;
- sniffer;
- dagger

kimi alət-ların praktiki olaraq məcburi olduğunu qeyd edir.

Əgər 5 slot-dan 3-ü mandatory-dirsə:

> 5 seçim yoxdur.

Real qərar space daha kiçikdir.

## 8.2. Dominant quruluş problemi

Long-play müsbət rəylərdə belə qeyd olunur ki:

- çox program var;
- amma effektiv bir configuration tapdıqdan sonra çox tapşırıq üçün onu dəyişməyə ehtiyac azalır.

Bu classic quruluş-system problemidir:

> məzmun variety var, strategic necessity azdır.

# 10. növbə əsaslı model hansı yeni problemi yaradır?

## 10.1. “Hacking yox, board game” gözlənti uyğunsuzluğu

Bütün mənfi rəy yoxlama-də ən aydın mövzu-lərdən biri budur.

Bəzi oyunçu üçün:

- qovşaqs = board spaces;
- programs = abilities/cards;
- SysOps = enemy pieces;
- two actions = board-game hərəkət büdcəsi.

Bu onlar üçün haker rol hissini zəiflədir.

Əsas problem mexanika-in keyfiyyəti yox, gözlənti-dır.

mağaza page taktiki RPG deyir, amma “hakerlik” word-u daha güclü prior gözlənti yarada bilər.

## 10.2. Typing-in oyun gedişi funksiyası azalır

Real-time Hacknet-də typing:

- speed;
- execution;
- pressure

ilə bağlıdır.

növbə əsaslı Midnight Protocol-da isə typing bəzən sadəcə UI qat-dir.

Bu bəzi rəy müəllifləridə belə sual yaradır:

> əgər time pressure yoxdur, niyə click etmək əvəzinə bunu yazmalıyam?

Deməli giriş thematicdir, amma mexaniki necessity hər zaman güclü deyil.

kimi anlaşılır.

# 12. yenidən cəhd / geri qaytarma / bərpa

RNG problemindən sonra ikinci böyük risk budur.

yenidən cəhd_ROLLBACK:

- 20 mentions
- 35% mənfi.

Complaint-lər:

- tapşırıq restart;
- geri qaytarma;
- wrong alət dəsti ilə ilişmək;
- re-plan etmək imkanı;
- əl ilə yadda saxlama;

- game restart ilə workaround.

Əsas dizayn principle:

> **uğursuzluq cost-u çətinlik ilə proporsional olmalıdır.**

Əgər oyunçu:

- bütün relevant info-ya sahib deyil;
- random outcome yaşayır;
- sonra permanent məzmun itirirsə

sistem unfair hiss olunur.

# 25. Niyə daha böyük hit olmayıb? — açıq hipotez

## 25.4. taktiki board-game identity hakerlik audience-in bir hissəsinə uyğun deyil

məhsul quality yaxşı olsa da TAM daha dar ola bilər.

## 25.5. Discoverability/marketing

son dövr rəylərdə “niyə bu oyun bu qədər bilinmir?” fikri görünür.

# 29. Hacknet ilə ilkin yekun fərq

Hacknet:

> daha sadə, daha dərhal rol hissi, daha az sistemli seçim.

Midnight Protocol:

> daha dərin taktiki/identity systems, amma daha yüksək cognitive və fairness risk.

Bunu belə xülasə etmək olar:

```text
Hacknet
fast rol hissi payoff
↓
simple loop
↓
repetition risk

Midnight Protocol
deeper decision model
↓
higher cognitive/system load
↓
fairness + onboarding + friction risk
```

Bizim gələcək concept üçün hədəf bu iki ekstrem arasında optimal nöqtə tapmaqdır.
