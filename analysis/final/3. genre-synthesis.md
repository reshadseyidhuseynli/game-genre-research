# Janr sintezi — Digital investigation / interface-as-world oyunları

## 1. Məqsəd

Bu sənəd ayrıca oyunların nəticələrini təkrar etmir.

Məqsəd tamamlanmış Tier A və focused comparator araşdırmalarından:

- təkrarlanan oyunçu rol hisslərini;
- uğur driver-larını;
- uğursuzluq pattern-lərini;
- dərinlik modellərini;
- interface dizaynı prinsiplərini;
- information-design qaydalarını;
- agency/consequence dərslərini;
- məhsul və market positioning nəticələrini

bir janr səviyyəli modeldə birləşdirməkdir.

Əsas araşdırma seti:

- Hacknet
- Midnight Protocol
- Cyber Manhunt
- The Operator
- Orwell: Keeping an Eye On You
- Mainlining
- SIMULACRA
- SIMULACRA 3

Focused comparator:

- Cyber Manhunt vs The Operator

# 2. Janrın ortaq nüvəsi

Araşdırılan oyunların təqdimatları fərqlidir:

- terminal;
- taktiki şəbəkə;
- browser/database;
- peşəkar iş stansiyası;
- surveillance platforması;
- desktop;
- telefon.

Amma oyunçunun əsas mental işi çox vaxt eynidir:

```text
məlumat al
→ relevance müəyyən et
→ əlaqə qur
→ hipotez yarat
→ qərar / əməl et
→ sistemin reaksiyasını gör
```

Janrın əsas fantasy-si:

> **“Mən ekranda görünən məlumatı başa düşürəm və sistemin məndən gözlədiyi düyməni deyil, vəziyyətin özünü həll edirəm.”**

Bu fərq kritiktir.

Əgər oyunçu:
- məlumatı özü mənalandırırsa,

oyun:
> araşdırma.

Əgər oyunçu:
- yalnız developer-in gizli trigger-lərini tapırsa,

oyun:
> progression puzzle.

# 4. Seçilmiş həqiqilik tam realizmdən daha sağlamdır

Bir neçə oyun eyni nəticəni verir.

### Hacknet

Real command/terminal hissi var, amma real hacking simulyasiyası deyil.

### Midnight Protocol

Texniki hiss yaradır, amma abstract turn-based sistem istifadə edir.

### The Operator

Peşəkar agentlik workstation hissi verir, amma məqsədli alətlərdən istifadə edir.

### SIMULACRA

Telefon reallığını verir, amma real OS deyil.

Ən sağlam model:

> **oyunçu rolunu inandırıcı edən detalları saxla; əyləncəni zəiflədən real-world friction-i daşımaya bilərsən.**

Problem:
- interface çox real görünürsə,
- amma basic real affordance-lar çatışmırsa,

expectation mismatch yaranır.

Mainlining və SIMULACRA bunu açıq göstərir.

### Principle

> **Realizm vizual oxşarlıq deyil; seçilmiş davranış consistency-sidir.**

# 7. Məlumat sıxlığı ilə məlumat yaxınlığı ayrı oxlardır

Cyber Manhunt:
- yüksək breadth;
- çox source;
- böyük information graph.

SIMULACRA:
- daha dar scope;
- çox yüksək şəxsi intimacy.

The Operator:
- dar və çox curated evidence set.

Orwell:
- geniş human profile;
- amma selection decision mərkəzdədir.

Bu göstərir ki:

> **“daha çox məlumat” avtomatik “daha dərin investigation” deyil.**

İki ayrı metric lazımdır:

1. **breadth** — neçə entity/source var?
2. **intimacy/depth** — hər entity haqqında nə qədər mənalı məlumat var?

SIMULACRA 3 göstərir ki breadth intimacy-ni əvəz etməyə bilər.

# 8. Productive noise — hər məlumat clue olmamalıdır

Investigation oyununda çox optimallaşdırılmış content:
- hər şey relevant;
- hər şey clickable;
- hər şey marker-lidir

olduqda:

> relevance tapmaq core verb olmaqdan çıxır.

SIMULACRA 1-in güclü hissəsi:
- şəxsi “lazımsız” data;
- random message;
- əlavə foto;
- incident detail.

Bunlar world-believability yaradır.

### Principle

> **Controlled irrelevant information discovery-ni mənalı edir.**

Amma noise:
- böyük;
- struktursuz;
- geri qayıtması çətin

olarsa UX problemi yaradır.

Buna görə:
> productive noise + strong external memory

birlikdə lazımdır.

# 10. Knowledge-state janrın ən fundamental sistem problemidir

Bu araşdırmada ən güclü cross-game pattern:

> **player knowledge ≠ system-recognized knowledge**

### Cyber Manhunt
Oyunçu cavabı bilir, amma scripted clue trigger lazımdır.

### Need to Know
Oyunçu doğru reasoning edir, amma exact rule/evidence state qəbul edilmir.

### Mainlining
Oyunçu cinayəti sübut edir, amma konkret evidence object tələb olunur.

### SIMULACRA
Məlumat tapılır, amma dialogue/progression trigger hələ açılmaya bilər.

### SIMULACRA 3
Relevance scan/Atlas state formal progression gate ola bilər.

### Əsas principle

> **Investigation sistemi click history-sini yox, semantic knowledge state-i modelləşdirməlidir.**

---

# 11. Knowledge state necə modelləşdirilə bilər?

Məlumatı file ID kimi yox:

```text
fact
source
confidence
entity
time
location
relationship
contradiction
```

kimi saxlamaq daha sağlamdır.

Məsələn:

```text
FACT: Alice was at Warehouse A at 22:15
SOURCES:
- CCTV frame 22:13
- Taxi receipt
- chat message

CONFIDENCE: high
```

Belə sistem:
- bir neçə source-u qəbul edə bilər;
- player alternative route istifadə edə bilər;
- stronger evidence weaker evidence-i əvəz edə bilər;
- progression semantic fact-a bağlana bilər.

Bu, araşdırmanın ən böyük sistem opportunity-lərindən biridir.

---

# 12. “Doğru cavab”dan çox “doğru səbəb” vacibdir

Digital investigation oyunlarında sistem çox vaxt:
- suspect seç;
- evidence seç;
- location seç

deyir.

Problem:
- oyunçu doğru cavabı guess edə bilər.

Daha güclü model:

> **oyunçu claim + justification təqdim edir.**

Məsələn:

```text
Claim:
X suspect-dir.

Because:
- source A
- source B
- contradiction C
```

Bu:
- reasoning-i visible edir;
- partial credit/failure feedback verir;
- semantic evidence system-i gücləndirir.

---

# 13. Failure feedback cavabı vermədən öyrətməlidir

Mainlining:
- hansı komponent səhvdir bilinmir.

Midnight Protocol:
- random/fairness perception uğursuzluğu izah etməyə mane ola bilər.

Cyber Manhunt:
- stuck state bəzən doğru query-ni guess etməyə çevrilir.

Sağlam failure feedback:

> **nə barədə yenidən düşünməli olduğunu göstərir, cavabı demir.**

Məsələn:
- identity mismatch;
- timeline conflict;
- evidence insufficient;
- source reliability low.

Bu deductive agency-ni qoruyur.

# 35. Janr üçün ən vacib 15 design principle

1. **Bir cümləlik rol fantasy-si qur.**
2. Interface-i world action-a çevir.
3. Seçilmiş həqiqilik istifadə et.
4. Familiar interface-in əsas affordance-larını saxla.
5. Məlumatı reward kimi dizayn et.
6. Player knowledge-ni semantic state kimi saxla.
7. Bir fact üçün birdən çox evidence route qəbul et.
8. Guidance interpretation-u oğurlamasın.
9. External memory təşkil etsin, cavab verməsin.
10. Depth meaningful decision density-dən gəlsin.
11. Repetition-i decision grammar dəyişərək qır.
12. Choice state divergence yaratmalıdır.
13. Consequence görünən, amma tam predictable olmamalıdır.
14. Recovery experimentation-a imkan verməlidir.

# 39. Son model

Bu janr üçün ən güclü ümumi loop:

```text
aydın rol
→ believable interface
→ rich but organized information
→ self-directed observation
→ player-built knowledge
→ hypothesis
→ meaningful action
→ visible consequence
→ changed information space
→ deeper hypothesis
```

Bu loop-da:

- UI world-dur;
- məlumat reward-dur;
- reasoning gameplay-dır;
- consequence retention driver-dir.
