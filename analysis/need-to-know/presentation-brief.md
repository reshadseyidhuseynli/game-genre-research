# Need to Know — Təqdimat xülasəsi

> **Görüş üçün qısa nəticə:** Need to Know çox güclü surveillance premise-i qurur və oyunçuya geniş mənəvi azadlıq vədi verir, amma əsas zəifliyi budur ki, UI/onboarding sürtünməsi, sərt rule-matching və bəzi məcburi progression yolları həmin azadlıq hissini zəiflədir. Orwell daha dar sistemlə daha az seçim səthi təqdim edir, amma qərarın nəticəsini daha aydın göstərdiyi üçün agency hissi daha güclü görünür.

## 1. Oyun nədir?

- Buraxılış: **28 avqust 2018**
- Yaradıcı / naşir: **Monomyth Games**
- Steam App ID: **490930**
- Janr mövqeyi: surveillance / bürokratiya / informasiya araşdırması / puzzle
- Araşdırma API snapshot-u: **272 ingilisdilli rəy**
- Müsbət rəylər: **65.44%**
- Median rəy-anı oyun müddəti: **7.99 saat**
- Steam mağaza səhifəsi ayrıca **175 rəy / 74% müsbət** göstərir; bu, API snapshot-u ilə eyni filtr səthi deyil.

## 2. Oyunçu burada nə yaşayır?

Əsas rol hissi:

> **“Mən dövlətin müşahidə aparatında çalışan analitikəm; insanların şəxsi məlumatlarını araşdırır və kimin təhlükəli olduğuna qərar verirəm.”**

Oyunçu:
- şəxsi profilləri və rəqəmsal izləri araşdırır;
- missiya qaydalarına uyğun dəlil axtarır;
- suspect-ləri qiymətləndirir;
- clearance artdıqca yeni surveillance gücləri açır;
- məlumat sata, gizli qruplarla işləyə və şəxsi maraq güdə bilir;
- dövlət, məxfilik və şəxsi qazanc arasında mövqe seçməyə çalışır.

## 3. Oyunçular niyə başlayır?

- “Big Brother-da sən sistemin içindəsən” premise-i çox aydındır.
- Başqalarının şəxsi rəqəmsal həyatına giriş marağı güclüdür.
- Dövlət müşahidəsi və privacy mövzusu real dünya ilə bağlıdır.
- Clearance progression daha çox güc və daha gizli məlumat vəd edir.
- Orwell və Papers, Please tipli audience üçün dərhal tanış məhsul dili yaradır.
- Mənəvi dilemma və “kimə xidmət edəcəyəm?” sualı ilkin hook-dur.

## 4. Oyunçular niyə davam edir?

- Story və siyasi thriller atmosferi.
- Clearance artdıqca yeni alət və səlahiyyətlər.
- Şəxsi profillərin getdikcə daha çox qatının açılması.
- Dövlətin həm faydalı, həm qorxulu tərəflərinin göstərilməsi.
- Bəzi yadda qalan missiyalar.
- Vizual təqdimat və soundtrack.
- Uzun oynayan bəzi oyunçular üçün routine məlumat təhlili özü rahatlaşdırıcı olur.

## 5. Ən güclü tərəflər

1. **Güclü və satıla bilən surveillance fantasy-si.**
2. **Moral ambiguity premise-i həqiqətən maraqlıdır.**
3. **Story və world-building oyunu daşıyır.**
4. **Clearance progression güc eskalasiyasını yaxşı hiss etdirir.**
5. **İnsan profilləri məlumat kəşfini emosional edir.**
6. **Dövlət tam karikatura deyil; həm real təhlükə dayandırır, həm də gücü sui-istifadə edə bilir.**
7. Bəzi missiyalar və situasiyalar uzun müddət yadda qalır.

## 6. Əsas zəif tərəflər

1. **İlkin öyrətmə və UI.** 0–1 saat qrupunda müsbət rəy yalnız **21.43%**-dir.
2. **Rule-matching problemi.** Oyunçu bəzən insan haqqında nəticə çıxarmaq əvəzinə sistemin hansı exact dəlili qəbul edəcəyini tapır.
3. **Məcburi progression.** Bəzi “seçimlər” alternativ yol yox, game over / retry yaradır.
4. **Dəlilin niyə qəbul və ya rədd edildiyi həmişə aydın deyil.**
5. **Təkrarçılıq.** Yeni feature-lərə baxmayaraq əsas qərar dövrü uzun müddət dəyişmir.
6. **Pacing.** Home/data-selling hissələri və çoxsaylı oxşar missiyalar story beat-lərini uzaqlaşdırır.
7. **Launch texniki borcu** çox yüksək olub; bəzi problemlər sonradan yaxşılaşsa da, struktur tənqidlər illər sonra da qalır.

Deterministik scan-da:
- ONBOARDING_CLARITY — **56.3% mənfi**
- UI_USABILITY — **49.2%**
- PUZZLE_CLARITY — **47.3%**
- DEDUCTION_REASONING — **59.1%**
- PRIVACY_SURVEILLANCE — yalnız **19.4%**
- MORAL_AMBIGUITY — yalnız **17.6%**

Bu, premise-in yox, execution qatının daha problemli olduğunu göstərir.

## 7. Kommersiya nəticəsi necə görünür?

**Güclü ilkin concept marağı, daha zəif davamlı məhsul reaksiyası.**

Faktiki siqnallar:
- Kickstarter kampaniyası güclü maliyyələşib;
- premise böyük maraq yaradıb;
- hazırkı Steam rəy həcmi nisbətən kiçikdir;
- research snapshot-da müsbət pay **65.44%**-dir;
- rəy məlumatında early-session friction çox güclüdür.

### Nəticəni izah edən əsas hipotezlər

- Concept acquisition yaradır, amma ilk saat promise-in payoff-ını gecikdirir.
- Marketing-də “öz qərarını ver” fantasy-si var, amma real oyun işi bəzən rule matching kimi hiss olunur.
- Geniş feature set real branch depth yaratmır.
- Uzunluq təkrar qərar qrammatikasını böyüdür.
- Launch technical debt ilk word-of-mouth-a zərər vermiş ola bilər.

Dəqiq satış məlumatı olmadan bunlar **hipotez** olaraq qalır.

## 8. Orwell-dan əsas fərqi nədir?

Orwell:

```text
məlumat tap
→ hansı məlumatı ötürəcəyini seç
→ adviser reaksiya verir
→ dünya dəyişir
```

Need to Know:

```text
rule oxu
→ profildə uyğun dəlili tap
→ təsnif et
→ çoxsaylı side/system qatları ilə irəlilə
```

Əsas fərq:

> **Orwell daha az seçim səthi ilə qərarın nəticəsini gücləndirir; Need to Know daha çox seçim səthi göstərir, amma onların bir hissəsi progression tərəfindən məcbur edilir.**

## 9. Bizim layihə üçün dərs

**Götür:**
- watcher rol hissi;
- privacy/surveillance premise-i;
- clearance ilə güc progression-u;
- moral ambiguity;
- insan profillərinin qat-qat açılması;
- story ilə sistemin eyni mövzunu daşıması.

**Qaç:**
- ilk saatda prosedur qarışıqlığı;
- semantik olaraq düzgün reasoning-i UI ritualına uduzdurmaq;
- moral choice-u game-over filterinə çevirmək;
- geniş feature set-i avtomatik dərinlik saymaq;
- bürokratik mövzunu pis UX ilə simulyasiya etmək;
- eyni qərar qrammatikasını həddindən artıq uzatmaq.
