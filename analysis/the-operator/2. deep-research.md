# The Operator — Dərin araşdırma

## Yekun xülasə

The Operator rəqəmsal araşdırma janrında oyunçuya **hadisə yerindəki agentlərə uzaqdan dəstək verən operator rolunu** inandırıcı şəkildə yaşadır. Oyunun əsas üstünlüyü geniş və sərbəst axtarış mühiti yaratmaqdan çox, xüsusi təhlil alətləri ilə hər epizodu keyfiyyətli tərtibat və filmə bənzər gərginliklə təqdim edərək oyunçunu oyun dünyasına bağlamasıdır.

Yoxlanmış Steam məlumat toplusu:

- **3,781 rəy**
- 3,392 müsbət
- 389 mənfi
- **89.71% müsbət rəy nisbəti**

Əsas nəticə:

> **The Operator Cyber Manhunt-da ipuclarının qeyri-aydınlığı və məlumat axtarışının qarışıqlığı problemini tapşırığa uyğun alətlər, daha aydın interfeys və yüksək təqdimat keyfiyyəti ilə azaldır; amma bununla oyunçunun sərbəstliyi və araşdırma zamanı nəticəni özü çıxarmaq imkanı da qismən azalır.**

Yəni problem belə dəyişir:

```text
Cyber Manhunt:
çox məlumat / sərt ipucu məntiqi
→ irəliləyə bilməmək və yalnız əvvəlcədən müəyyən edilmiş yolu izləmək hissi

The Operator:
problemə uyğun seçilmiş məlumat / güclü yönləndirmə
→ daha az çaşqınlıq
→ amma həddindən artıq yönləndirmə və sərbəst qərar imkanlarının azalması riski
```

The Operator-un əsas üstünlükləri:

- operator rolunu inandırıcı şəkildə yaşatması;
- diqqətlə hazırlanmış uydurma əməliyyat sistemi;
- səs və səsləndirmə;
- aydın və müxtəlif xüsusi tapmaca səhnələri;
- triller ritmi;
- qısa oyun müddəti sayəsində təkrarçılığın az hiss olunması;
- güclü hekayə təqdimatı.

Əsas zəifliklər:

- xətti irəliləyiş;
- seçimlərin zəif nəticə yaratması;
- həddindən artıq yönləndirmə;
- mexanikaların yalnız bir dəfə istifadə olunması və daha mürəkkəb istifadəyə keçilməməsi;
- qısa məzmun;
- yenidən oynamağın və əvvəlki vəziyyətə qayıtmağın çətinliyi;
- sonluğun hekayəni tam yekunlaşdırmamasından yaranan narazılıq.

Ən vacib dizayn dərsi:

> **Araşdırma oyununda çaşqınlığı azaltmaq üçün oyunçunun sərbəst düşünmək imkanını məhdudlaşdırmaq lazım deyil. Oyun həm aydın olmalı, həm də sərbəst qərar verməyə imkan yaratmalıdır.**

# 3. Oyunun mahiyyəti

Ən düzgün qısa təsvir:

> **Dövlət qurumunun uydurma əməliyyat sistemində operator kimi işləyərək araşdırma apardığın və tapmacalar həll etdiyin hekayə yönümlü oyun.**

Əsas oyun dövrü:

```text
agentdən problem al
→ dəlili aç
→ uyğun təhlil alətini seç
→ vacib məlumatı müəyyən et
→ nəticəni agentə bildir
→ yeni dəlil və ya hekayə hadisəsi açılır
→ həll ediləcək növbəti konkret problemə keç
```

Bu, Cyber Manhunt-un:

```text
axtarış → profil → hesab → ipucu → növbəti məlumat
```

dövründən daha məhdud, məlumatları əvvəlcədən seçilmiş və gedişi daha çox yönləndirilən quruluşdur.

### Prinsip

# 19. Təkrarçılıq

The Operator rəylərində təkrarçılıq Hacknet və Cyber Manhunt-la müqayisədə xeyli az önə çıxır.

Bu əsasən:

- qısa oyun müddəti;
- çoxlu birdəfəlik alət;
- səhnə müxtəlifliyi

sayəsindədir.

Bu, riskin uğurlu şəkildə məhdudlaşdırılması nümunəsidir.

Amma bu yanaşmanın çətinlikləri də var:

- oyunçunun alətlərdən istifadə bacarığını inkişaf etdirmək imkanları azalır;
- eyni mexanikalar daha az təkrar istifadə olunur;
- məzmun istehsalı bahalaşır.

### Üstünlük və onun əvəzində yaranan çətinliklər

```text
daha çox xüsusi hazırlanmış epizod
→ daha az təkrarçılıq
→ alət və mexanikaları dərindən mənimsəmək üçün daha az imkan
→ daha yüksək məzmun istehsalı xərci
```

Bu, gələcək oyun ideyası üçün istehsal baxımından çox vacibdir.

**Fikir ayrılığı yaradır.**

## Hekayədən doğan alət dizaynı

**Müxtəliflik baxımından uğurlu, təkrar istifadə baxımından zəifdir.**

Alətlər hekayə hadisələrini yaşatmağa yaxşı xidmət edir, amma onlardan təkrar və fərqli üsullarla istifadə imkanları məhdud qalır.

# 21. Cyber Manhunt ilə əsas fərq

Cyber Manhunt-un risk modeli:

```text
geniş axtarış
→ ipuclarının qeyri-aydınlığı
→ konkret irəliləyiş şərti
→ irəliləyə bilməmək / məyusluq
```

The Operator:

```text
konkret problemə uyğun alət
→ aydın məqsəd
→ güclü yönləndirmə
→ daha az qeyri-müəyyənlik
→ daha az sərbəst qərar imkanı
```

Bu iki oyun araşdırma dizaynında iki əks ifratı göstərir:

```text
HƏDDİNDƏN ARTIQ AÇIQ / QEYRİ-MÜƏYYƏN
←-----------------------------------→
HƏDDİNDƏN ARTIQ YÖNLƏNDİRİLƏN / ƏVVƏLCƏDƏN MÜƏYYƏN EDİLMİŞ
```

Gələcək oyun üçün hədəf:

> **oyunçuya dəlillərlə necə işləməyi göstərən aydın qaydalar + eyni nəticəyə fərqli, əsaslı yollarla çatmaq imkanı.**

göndərə bilər.
