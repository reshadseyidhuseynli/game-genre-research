## Niyə növbəti target budur?

Cyber Manhunt araşdırması göstərdi ki, digital-investigation oyunlarında əsas risklər:
- scripted clue order;
- oyunçu knowledge-in game state tərəfindən tanınmaması;
- weak dəlil UX;
- investigation-ın checklist-ə çevrilməsi;
- hekayə və UI-nin deduction-u əvəz etməsidir.

The Operator bu sualları test etmək üçün güclü reference-dir, çünki onun əsas fantasy-si “field agent” olmaq yox, **arxa planda məlumat analiz edən operator** olmaqdır.

## yaradıcı intent

yaradıcı Bastien Giafferi The Operator-u X-Files və Her hekayə təsirlərinin qarışığı kimi izah edir.

Core inspiration:

> əsas agent olmaq əvəzinə “chair arxasındakı” analyst/operator rolunu oynamaq.

Game yaradıcı müsahibəsində interface və təhlil tools-un hekayə beat-lərlə birlikdə dizayn edildiyi vurğulanır.

Bu bizim araşdırma üçün çox vacibdir, çünki Cyber Manhunt-da UI tez-tez clue tapma çətinlik-i yaradırdı. The Operator isə UI-ni investigation sisteminin mərkəzi kimi nəzərdə tutur.

yaradıcı ayrıca oyuna dalma hissi üçün fictional desktop və terminal kimi secondary tools da daxil edib; terminal əvvəlcə daha böyük rol üçün nəzərdə tutulsa da final dizayn-də əsas mexanika yox, world-completeness elementi kimi saxlanıb.

## Əsas araşdırma sualları

1. oyunçu həqiqətən deduction edir, yoxsa hekayə yalnız doğru tool-u seçməyə yönəldir?
2. dəlil system oyunçu-in artıq bildiyi nəticəni qəbul edirmi?
3. UI external working memory kimi Cyber Manhunt-dan daha yaxşı işləyirmi?
4. Cases oyunçu-a bir neçə valid reasoning route verir?
5. Investigation puzzle-ləri fair və explainable-dırmı?
6. hekayə mystery-ni gücləndirir, yoxsa autonomy-ni məhdudlaşdırır?
7. Game length və pacing təkrarçılıq problemini necə idarə edir?
8. Analyst/operator fantasy hacker fantasy-dən daha geniş audience cəlb edirmi?
9. oyunçu hansı anda “mən tapdım” hissini yaşayır?
10. Cyber Manhunt-un early-session risk nümunə-i burada da görünürmü?

## İlkin müqayisə hipotezi

Cyber Manhunt:

```text
information discovery
→ strong fantasy
→ strict scripted progression
→ deduction friction
```

The Operator üçün test ediləcək model:

```text
specialized analysis tools
→ focused evidence comparison
→ explicit reasoning
→ potentially lower search ambiguity
```

Əgər oyunçu response bunu təsdiqləsə, vacib principle çıxacaq:

> Investigation dərinlik üçün böyük açıq search space şərt deyil; əsas məsələ oyunçu-in dəlil üzərində real inference etməsidir.
